# EventTrackBot

Телеграм-бот, который ищет мероприятия и события, связанные с программированием, в выбранном городе России и присылает новые находки, пока поиск не остановлен.

## Что умеет

- Выбор города России: популярные города кнопками или ввод своего названия.
- Кнопка **«🔎 Найти мероприятия»** запускает постоянный мониторинг.
- Кнопка **«⏹ Остановить поиск»** останавливает мониторинг. После остановки можно сменить город или запустить поиск снова.
- Поиск идёт в интернете: бот проверяет прямые источники, собирает ссылки через Bing/Yahoo/DuckDuckGo, открывает страницы мероприятий и разбирает:
  - название;
  - дату и время;
  - город, площадку и адрес;
  - постер (если есть);
  - описание;
  - организатора;
  - ограничения (например, возрастные);
  - источник и ссылку на страницу;
  - как попасть / где зарегистрироваться;
  - цену. Если вход платный, показывается зелёный значок **💵** и сумма в рублях. Для бесплатных мероприятий цена не выводится.
- Уже отправленные мероприятия не дублируются.
- Состояние сохраняется в `data/users.json`, поэтому после перезапуска бота мониторинг и список просмотренных событий восстанавливаются.

## Установка

Нужен Python 3.10+.

```bash
git clone https://github.com/enty9/EventTrackBot.git
cd EventTrackBot

python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

pip install -r requirements.txt
```

Создай файл `.env` на основе примера:

```bash
cp .env.example .env
```

Вставь токен бота от [@BotFather](https://t.me/BotFather):

```env
BOT_TOKEN=123456789:AA...
```

## Запуск

```bash
python bot.py
```

Дальше в чате с ботом:

1. `/start`
2. Выбери город.
3. Нажми «🔎 Найти мероприятия».
4. Чтобы остановить — «⏹ Остановить поиск».

## Настройки

Все параметры лежат в `.env`:

| Переменная | По умолчанию | Описание |
|---|---:|---|
| `BOT_TOKEN` | — | Токен Telegram-бота, обязателен |
| `SEARCH_INTERVAL_MINUTES` | `20` | Интервал повторной проверки, минимум 5 минут |
| `MAX_EVENTS_PER_CYCLE` | `6` | Сколько новых мероприятий отправлять за цикл |
| `SEARCH_RESULTS_PER_QUERY` | `10` | Сколько ссылок брать с одной поисковой выдачи |
| `SEARCH_MAX_URLS` | `30` | Максимум страниц для проверки за один поиск |
| `SEARCH_MAX_EVENTS` | `50` | Максимум подходящих мероприятий за один поиск |
| `DATA_FILE` | `data/users.json` | Файл состояния |
| `USER_AGENT` | браузерный | User-Agent для запросов |

## Как работает поиск

1. Бот проверяет прямые источники мероприятий: freeitevent.ru, hacklist.ru и каталог ICT2GO для поддерживаемых городов.
2. Дополнительно формирует несколько запросов вида «IT-конференция Москва», «хакатон Казань», «митап разработчиков» и получает ссылки через Bing, Yahoo и DuckDuckGo (по очереди, с фолбэком).
3. Загружает страницы и ищет разметку `schema.org/Event` в JSON-LD, а также запасной вариант — Open Graph / `time[datetime]`.
4. Отфильтровывает события не по теме, прошедшие события, страницы-афиши и события из другого города.
5. При необходимости открывает страницу конкретного мероприятия, чтобы добрать дату, постер, описание или цену.
6. Конвертирует цену в рубли по курсу ЦБ РФ (если цена была в другой валюте и курс доступен).
7. Отправляет карточку с постером и подробностями.

Поиск и разбор страниц работают без API-ключей. Если поисковики временно ограничивают запросы, бот продолжает использовать прямые источники.

## Ограничения

- Бот не имеет доступа к «всему интернету» и не гарантирует, что найдёт абсолютно все мероприятия. Он зависит от поисковой выдачи и разметки сайтов.
- DuckDuckGo может ограничивать частые запросы. При большом количестве пользователей стоит увеличить интервал или подключить платный поисковый API/прокси.
- Не все сайты размещают дату и цену в машиночитаемом виде. Такие страницы могут быть пропущены.
- Бот не покупает билеты и не регистрирует на мероприятия — он даёт ссылку и информацию.

## Структура проекта

```
bot.py                 — точка входа
app/
  config.py            — настройки из .env
  handlers.py          — команды и кнопки Telegram
  keyboards.py         — клавиатуры
  manager.py           — фоновый мониторинг и остановка
  storage.py           — сохранение состояния
  formatting.py        — тексты карточек
  sender.py            — отправка постеров и сообщений
  cities.py            — список городов и проверка названий
  models.py            — модель мероприятия
  money.py             — цены и валюты
  timeutil.py          — даты и часовой пояс
  search/
    engine.py          — поиск, фильтрация, кеш
    direct.py          — прямые источники мероприятий
    bing.py            — поиск Bing
    yahoo.py           — поиск Yahoo
    ddg.py             — DuckDuckGo
    extract.py         — разбор JSON-LD/OG
    currency.py        — курсы валют ЦБ
tests/                 — офлайн-тесты разбора
```
